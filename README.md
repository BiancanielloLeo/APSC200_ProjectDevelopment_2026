##APSC200_ProjectDevelopment_2026

This repository contains the code and documentation for the SWEP 2026 project. Please refer to Setup_Information file to start using the system, and read Project_Information file to understand all of the details of the project.

When navigating the repository:
+ The "Software" folder contains all code to be ran on the computer.
+ The "Firmware" folder contains all the code to be ran on the robots.
+ The "Hardware" folder contains all the CAD models for the robots.
